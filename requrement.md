# A Celebration of Love

Sri Lankan Traditional Wedding · Watercolour & Lotus Theme

## 1. Project Overview

Develop a modern, elegant, responsive wedding invitation website that allows the wedding organizers to manage guest invitations individually and collect RSVPs online.

The website should provide a personalized digital wedding invitation for every guest.

The main functionality is:

- The wedding administrator can add guest names to the system.
- The system automatically generates a unique invitation URL for each guest.
- The administrator can share the generated URL through WhatsApp, email, or other platforms.
- When a guest opens the link, they should see a personalized wedding invitation addressed specifically to them.
- Guests can view all wedding information and submit their RSVP, confirming whether they will attend and how many people will be attending.

The entire website should reflect the elegance of a traditional Sri Lankan wedding, combined with a modern and sophisticated watercolour aesthetic.

Important technical requirements:

- Each guest must have a unique, secure invitation token.
- Guest information should be dynamically loaded using that token.
- Invitation links must not expose sequential guest IDs or personal information.
- RSVP data must be stored in a database.
- Each invitation must enforce its assigned guest limit on the server, not only in the frontend.
- Admin access must be protected.
- The website should be optimized for mobile devices.
- Guest data should be handled securely.

## 7. Expected User Journey

Administrator journey

1. Log into the admin dashboard.
2. Add a guest's name and contact information.
3. Set the maximum number of attendees.
4. Generate a unique invitation link.
5. Copy or share the link through WhatsApp.
6. Track the guest's RSVP status.
7. Download the final guest list.

Guest journey

1. Receive a personalized invitation link.
2. Open the website on their mobile phone.
3. See their name on the wedding invitation.
4. Read wedding details and venue information.
5. Select whether they will attend.
6. Enter the number of attendees.
7. Submit the RSVP.
8. Receive an on-screen confirmation.
